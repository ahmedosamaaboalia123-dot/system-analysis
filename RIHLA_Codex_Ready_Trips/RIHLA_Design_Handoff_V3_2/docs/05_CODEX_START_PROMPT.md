# 05 — Prompt جاهز لـ Codex (Trips Full Prototype)

هذا الملف يحل محل النص القديم الذي كان يبدأ بخطة ويتوقف لطلب الموافقة؛ التعديل **خاص بمهمة موديول الرحلات كنموذج مستقل**، ولا يُغيّر مواصفات تصميم V3.2.

انسخ نص `START_CODEX_HERE.md` الموجود في جذر الحزمة إلى Codex بعد وضع محتويات الحزمة في الريبو أو إتاحتها ضمن بيئة المهمة.

**لا تستخدم النص القديم "خطة تنفيذ أولًا، لا تبدأ بتغيير الكود مباشرة" لهذه المهمة.**

المطلوب: قراءة المستندات، وضع خطة قصيرة مكتوبة، تنفيذ كل مكونات الرحلات، اختبار فعلي، تحديث User Story coverage وQA وModule Report، إنشاء Commit وPR على feature branch إن توفرت الصلاحيات. بدون توقف للموافقة بعد كل مرحلة، بدون الدمج في main، وبدون ادعاء نجاح اختبارات لم تُشغّل.
