# موديول الرحلات — تقرير التسليم

**الحالة:** التخطيط وتوثيق قصص المستخدم فقط — لم يُنفذ HTML بعد.

## الغرض
نموذج UI تفاعلي مستقل باللغة العربية RTL لموديول الرحلات، يسلم كمرجع لفريق الـBackend، لا كنظام إنتاجي.

## ما تم إنجازه
- إعداد User Stories ومعايير قبول مبنية على مواصفات الرحلات الموحّدة.
- إعداد تعليمات Codex وخطة تسليم تدريجية.
- إعداد QA Checklist (جميع بنودها NOT RUN حتى تسليم النموذج).

## حالة التنفيذ
- HTML/CSS/JS: **لم يبدأ**.
- Browser/Functional Tests: **لم تُنفذ**.
- Integration with Backend: **خارج النطاق الحالي**.

## القرارات التشغيلية المفتوحة
القرارات [حاسم-01] إلى [حاسم-18] واردة في المستند المرجعي، وغير معتمدة بعد. يجب ألا تتجسد في الكود كقواعد نظام مؤكدة.

## ملاحظات لصاحب الـBackend
- Mock Data لا تمثل المصدر النهائي للسجلات؛ سيكون مصدر الطيران والفنادق والعملاء والمشرفين من الموديولات الخاصة بها.
- الحسابات المالية وحركات الدفع المعروضة، إن نُفذت، هي محاكاة واجهة فقط.
- نموذج HTML هو مرجع لسلوك الواجهة، وليس API Specification نهائيًا.

## تحديثات مراحل Codex
يُستكمل هذا القسم بعد تسليم كل مرحلة: تاريخ، نطاق، Story IDs، ما تحقق فعلاً، الـBugs، الاختبارات، والأسئلة.
